# Contributing to the IPC Project

Thanks for your interest in contributing to this project.

## Code of Conduct

Please be respectful, constructive, and professional in all communication, we expect contributors to help maintain a welcoming, inclusive environment.

## How to Contribute

You can contribute by:
- adding tests
- reporting bugs
- suggesting improvements
- fixing issues
- improving documentation
- proposing or implementing features
- or anything more you deem useful
Before starting work, please check the issue tracker to see whether the topic is already being discussed.
